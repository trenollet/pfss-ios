# PFSS Feature Specifications

- Status: Active
- Owner: PFSS Project
- Last Updated: 2026-08-07

This folder contains detailed behavioral specifications for PFSS capabilities. A feature document should describe user goals, workflow, data behavior, edge cases, completion criteria, and links to applicable standards and ADRs.

Feature specifications will be added or expanded when the corresponding subsystem is actively designed. Planned subjects include:

- Customers and Sites
- Leads
- Estimates and the WorkOrder Engine
- Jobs and Guided Workflow
- Invoices, Payments, and Receipts
- Scheduling and Workforce Management
- Service Catalog and Recommendations
- Time Tracking and Reporting
- Route Planning
- Bluetooth Receipt Printing

Active Phase 18 specifications:

- `FieldPricingCalculator.md`
- `MapAssistedAddressEntry.md`
- `OperationsCalendar.md`
- `RecurringWork.md`

Do not create empty feature documents merely to fill the directory. Add a specification when there is verified behavior or an approved design to preserve.

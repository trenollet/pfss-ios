# v0.6 - Complete WorkOrder Engine

## Status

Completed

## Summary

v0.6 completed the core WorkOrder Engine for PFSS.

This milestone changed PFSS from a collection of forms into a reusable work order platform that can support estimates, jobs, invoices, and receipts.

## Highlights

- Shared `WorkOrderEditorView`
- `LineItemListView`
- `LineItemRowView`
- `EditableLineItemView`
- `WorkOrderTotalsView`
- Catalog-based line item creation
- Custom line item creation
- Edit existing line items
- Duplicate line items
- Delete line items
- Native swipe actions
- Shared pricing display

## Architectural Impact

This milestone established the reusable WorkOrder Engine as one of the central foundations of the platform.

Future modules such as invoices, receipts, and recurring maintenance should reuse this engine rather than create separate line item workflows.

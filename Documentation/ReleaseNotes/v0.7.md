# v0.7 - Intelligent Service Catalog

## Status

In Progress

## Summary

v0.7 focuses on making the Service Catalog feel intelligent by ranking results according to human search behavior, usage, and recency.

## Completed So Far

- Renamed search concept into `CatalogRankingEngine`
- Added scoring pipeline
- Added token-based search
- Added initialism matching
- Added usage scoring
- Added recency scoring
- Added debug ranking output

# PFSS Phase 18 Project Workbook

## Product Expansion

**Status:** Planning

**Created:** 2026-08-06

## Phase Objective

Expand PFSS with the next approved set of customer, sales, field-service,
scheduling, reporting, and usability capabilities while preserving the
production-account, authorization, synchronization, recovery, entitlement, and
Operations foundations completed in Phase 17.

## Planning Rule

The Phase 18 feature plan will be built with the product owner after Phase 17
closeout. This workbook intentionally does not preselect features from the
parking lot. Candidate work must be prioritized, scoped, given acceptance
criteria, and checked for cross-device, role, synchronization, migration, and
server impacts before implementation begins.

## Required Planning Outputs

- [ ] Select the Phase 18 product theme and prioritized feature set.
- [ ] Separate committed work from parking-lot and post-v1.0 ideas.
- [ ] Define user stories and role-specific behavior.
- [ ] Define data-model, migration, synchronization, and server changes.
- [ ] Define iPhone and iPad interface acceptance criteria.
- [ ] Define automated regression and live-device test matrices.
- [ ] Establish the Phase 18 delivery order and completion gate.

## Entry Gate

- [x] Phase 17 production-account platform completed.
- [x] App Store deployment separated into Phase 19.
- [ ] Product owner approves the Phase 18 implementation plan.
